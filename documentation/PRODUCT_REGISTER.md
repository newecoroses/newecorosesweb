## Section 3: Product Numbering System — Proposed (Awaiting Approval)

> [!WARNING]
> The following SQL migration would add a permanent `product_number` column to the Supabase `products` table.
> **This has NOT been applied.** It requires explicit approval before execution.

```sql
-- Add product_number column to Supabase products table
ALTER TABLE products ADD COLUMN IF NOT EXISTS product_number INTEGER UNIQUE;

-- Create a sequence for safe auto-increment
CREATE SEQUENCE IF NOT EXISTS product_number_seq START 1;

-- Function to auto-assign on insert
CREATE OR REPLACE FUNCTION allocate_product_number()
RETURNS TRIGGER AS $$
BEGIN
  IF NEW.product_number IS NULL THEN
    NEW.product_number := nextval('product_number_seq');
  END IF;
  RETURN NEW;
END;
$$ LANGUAGE plpgsql;

-- Trigger on every new product insert
CREATE TRIGGER auto_product_number
  BEFORE INSERT ON products
  FOR EACH ROW EXECUTE FUNCTION allocate_product_number();

-- Backfill existing 319 products with sequential numbers
UPDATE products p
SET product_number = sub.rn
FROM (
  SELECT id, ROW_NUMBER() OVER (ORDER BY created_at ASC NULLS LAST) AS rn
  FROM products
) sub
WHERE p.id = sub.id;
```
